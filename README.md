# Agribot India 

Agribot India is a student-built smart agriculture project focused on using
**Python and IoT** to help farmers monitor field conditions and protect crops.

This project is being built publicly as a learning journey.

---

##  Features (Planned & In-Progress)
- Environmental monitoring using sensors (temperature, humidity, soil moisture)
- Python-based data processing and alerts
- **Scare Buzzer system** to protect crops from animals
- Modular design for future AI/ML integration

---

##  Why Agribot India?
Small and medium farmers often lack affordable technology.
Agribot India aims to explore **low-cost, practical solutions** using IoT.

---

##  Tech Stack
- Python
- IoT Sensors
- Microcontrollers (Arduino / ESP – planned)
